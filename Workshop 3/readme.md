Työpaja 3: JavaScript-tapahtumat

    Harjoitus 1: Painikkeiden onclick-tapahtumat ja eläintaulukon luominen.

    Harjoitus 2: mouseover- ja click-tapahtumat sekä addEventListener().

    Harjoitus 3: focus-, blur- ja input-tapahtumat palautelomakkeessa.

    Harjoitus 4: Lomakkeen lähetys, tekstin pituuden tarkistus ja preventDefault().

    Harjoitus 5: Näppäimistön keydown-tapahtuma, näppäimen näyttäminen ja laskuri.

    Bonustehtävä: Taustavärin vaihtaminen sekä Shift-, Ctrl- ja Alt-näppäinten tunnistaminen.

    Bonusharjoitus: Käyttäjän sijainnin avaaminen Google Mapsissa.
